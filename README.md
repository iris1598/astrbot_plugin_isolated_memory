## 🌟 核心特性

- 🧠 **随时间衰减的长期记忆引擎**：
  基于共享向量知识库，按「群×成员」严格隔离。引入艾宾浩斯时间衰减（半衰期模型）、BM25+稠密向量混合检索、MMR 多样性去重、上下文扩展检索、Cross-Encoder Rerank 神经精排与重要事实永久保护。
- 💞 **原生羁绊好感度与自由式关系**：
  彻底废除 0~100 死板数值封顶，数值无上下限积攒；告别死板线性关系阶梯，由大模型根据相处语境自由提出独一无二的羁绊名称（如“互怼损友”、“默契搭档”）；保留玩家确认交互，安全可控。
- 🎭 **即时轻量心境系统（Transient Mood）**：
  赋予 Bot 鲜活情绪波澜（开心、赌气、害羞、委屈等），1~2 轮自然平复自愈，绝不死锁或粗暴禁言，告别假人人设。
- ✨ **鸣潮角色共鸣评测（xxti）**：
  免 Token 消耗！读取用户记忆通过词向量语义锚点匹配 24 位鸣潮角色（今汐、长离、折枝、忌炎、守岸人、椿等），本地 Pillow 超采样渲染精美「人格弹珠」风格角色共鸣海报。
- 🗂️ **官方会话管理工具集**：
  中文命令操作官方多对话上下文（`/会话重置`、`/会话信息`、`/存档`、`/读档`、`/存档列表`、`/删档`），存档即官方对话，WebUI 对话管理完全互通。
- 🖥️ **现代可视化管理后台（WebUI Pages）**：
  原生集成于 AstrBot 插件管理页，提供记忆多维检索/编辑/导出导入、检索测试、好感度在线管理与图表概览。
- 🖼️ **本地原生 Pillow 高清海报直出**：
  个人好感名片、群好感排行榜（TOP 10 / 倒序）与鸣潮共鸣档案均基于本地 Pillow 极速渲染，**0 浏览器与 Playwright 依赖**，毫秒级直出。
- 🛡️ **无缝数据迁移与 100% 向后兼容**：
  自动侦测并平滑迁移 `astrbot_plugin_favorability` 历史数据，配置自适应穿透查找，升级不丢数据。

## 🖥️ 内置可视化管理仪表盘（WebUI Pages）

本插件内置了现代仪表盘管理界面，无需繁琐命令，在 AstrBot WebUI 中点击本插件的「**Pages / 页面**」按钮即可直接打开：

1. **记忆管理（Memories）**：
   - 表格化浏览知识库中的全部记忆，按群与用户归属（UMO）清晰呈现。
   - 支持关键词搜索、用户筛选、事实类型过滤与重要度排序。
   - 侧边抽屉面板（Peek Panel）：直接在线编辑记忆文本、微调重要度（0.1~1.0）与类型，或删除单条。
   - 批量管理：多选批量删除、导出为 JSON/CSV 数据文件、从本地文件导入记忆。
2. **检索测试（Recall Test）**：
   - 网页端直接调试混合检索与时间衰减打分，实时查看召回排名、相关度、距离天数与综合有效得分。
3. **好感度管理（Affinity）**：
   - 卡片化浏览各群各用户的好感档案、当前自由关系、即时心境与人格评价。
   - 支持在线手动修改好感数值、编辑关系、修改评价或一键重置。
4. **系统概览与备份（System Overview）**：
   - 统计卡片：记忆总数、活跃条数、独立用户数、平均重要度。
   - 图表统计：记忆重要度分布直方图、事实类型分布柱状图、活跃记忆用户排行。
   - 快照备份：查看历史备份文件、一键创建快照备份、一键安全还原记忆库。

## 🧠 衰减长时记忆引擎架构

```
【用户发言】
   │
   ├─► 1. 上下文扩展（若发言 ≤15 字符，融合上轮助手回复避免脱靶）
   ├─► 2. 意图动态识别（偏好 / 人设档案 / 未来日程 / 近期回顾 / 通用）
   ├─► 3. 严格隔离过滤（按当前事件 UMO = 平台:GroupMessage:用户_群）
   │      │
   │      ▼
   │   混合多路初筛（稠密向量召回 + BM25 稀疏召回 + RRF 倒数融合）
   │      │
   │      ▼
   │   Cross-Encoder Rerank 神经精排（可选对接原生 Rerank 模型，异常自动无感降级）
   │      │
   │      ▼
   │   意图定向 Boost + MMR 多样性打散（防止近义重复挤占窗口）
   │      │
   │      ▼
   │   动态衰减综合评分排序（天数半衰期 + 重要度加权）
   │      │
   │      ▼
   ├─► 4. 防幻觉与时效护轨结构化注入（分类标记 + 相对时间锚点 + 最新发言优先准则）
   │
   ▼
【大模型回复】
   │
   ├─► 5. 命中记忆刷新时间戳（回忆强化）+ 惰性清理过期与 LRU 超限记忆
   │
   └─► 6. 后台异步抽取（每 N 轮聚合对话，原子化提炼事实/偏好/日程，去重写入知识库）
```

### 动态衰减打分算法

综合有效得分公式：
$$Score = w_{rel} \cdot \text{相关度} + w_{imp} \cdot \text{重要度} + w_{rec} \cdot 0.5^{\frac{\text{天数}}{\text{半衰期}}}$$

- **半衰期衰减**：旧记忆随天数增加自然衰减；每次被对话成功召回时会自动刷新时间戳（**回忆强化机制**）。
- **核心记忆永久保护**：重要度 $\ge 0.85$ 的核心记忆（如姓名、偏好禁忌、过敏史、关键关系）享有特权保护，不受 TTL 过期清扫和 LRU 容量淘汰影响。

### 双路召回与 Rerank 神经精排

- 支持结合关键词精准度的 BM25 与语义理解的 Dense 向量，通过 RRF（Reciprocal Rank Fusion）多路召回候选池。
- 可选开启 **Rerank 神经精排**：调用 AstrBot 配置的 Cross-Encoder 模型（如 bge-reranker）对候选记忆深度语义打分，大幅提升长难句与隐式查询的命中率。

### 防幻觉与时效护轨注入

注入到大模型上下文中的记忆采用结构化分类包裹：
```markdown
--- BEGIN USER BACKGROUND MEMORY ---
【历史记忆参考】以下为过去对话中沉淀的用户背景信息，仅供对话理解与个性化参考：
- [用户偏好/禁忌] 喜欢喝无糖乌龙茶，对芒果轻微过敏（约12天前）
- [既定计划/日程] 周末准备去参加动漫展（今天）

【防幻觉与冲突准则】：
1. 以上均为过往事实背景，并非当前正在发生的新事件。
2. 若上述历史记忆与用户「当前最新发言」存在矛盾或变更，必须无条件以用户当前的最新表述为准。
3. 请自然融入对话，切勿生硬复读记忆原文或反客为主。
--- END USER BACKGROUND MEMORY ---
```

### 低价值碎片记忆自动整理（Consolidation）

后台可启用记忆库自动整理机制：针对创建超过一定天数的零散、低权重碎片记忆，由后台 LLM 定期聚类、提炼并归纳为更高阶的长期记忆，删除冗余碎片，从源头控制知识库膨胀。

## 💞 原生羁绊与即时心境系统

### 打破天梯：数值退居幕后
传统插件往往使用 0~100 的固定天梯，老用户几天就刷满好感，数值失去意义；或者让数值强行霸道决定模型态度。
- **本系统数值无上下限**：支持负数、几千乃至上万分，平滑记录互动陪伴的长久深度。
- 数值退居幕后仅作为陪伴厚度参考，模型态度更加自然生动。

### 大模型主导自由式关系（Free-form）
告别死板的固定关系档位：
- 大模型根据当前性格人设与真实相处经历，可随时提议自由羁绊（如：“默契搭档”、“异次元知己”、“并肩作战的战友”等）。
- 提议后触发确认流程，用户输入 `/确认关系` 即可正式确立羁绊；变动与确认时精准 `@` 对应成员，群体聊天绝不混淆。

### 即时心境（Transient Mood）自然自愈
- 解决好感度高时 Bot 永远只会“傻白甜微笑”的人设扁平问题。
- 大模型可在单轮对话中表现出生动心境（如：“小傲娇”、“微嗔”、“感动”、“期待”等）。
- 心境具备 **1~2 轮自然平复生命周期**，随后自动恢复常态，绝不死锁，杜绝暴力禁言。

### 多重人格（Persona）严格独立隔离
- 同一用户在不同人格（Persona）下的好感度数值、关系羁绊、即时心境与评价**严格按人格分别存储**。
- 无论你是切换猫娘、高冷御姐还是硬核管家，每个人格都拥有对该用户的独家记忆与羁绊档案，切换人格绝不串味。

## ✨ 鸣潮角色共鸣评测（xxti）

群成员直接发送 `xxti`（或 `/xxti`、`/记忆测评`）即可发起角色共鸣评测：

- **0 Token 零大模型开销**：完全基于用户记忆向量与 24 位鸣潮角色的性格标签/代表台词的语义锚点计算余弦契合度，速度极快且结果客观稳定。
- **24 位鸣潮全角色矩阵**：涵盖今汐、长离、折枝、忌炎、守岸人、椿、相里要、安可、散华、维里奈、白芷、丹瑾、炽霞、桃驰、秧秧、渊武、莫特斐、卡卡罗、秋水、凌阳、漂泊者等全部角色。
- **Pillow 高清海报渲染**：直接在本地生成紧凑精美的「人格弹珠」风格角色共鸣档案海报，展示全域共鸣度分布雷达条、第一契合角色立绘称号、角色代表台词与最契合记忆依据。
- **隐私保护**：只读分析已保存记忆，不回写记忆库；海报完全不泄露用户的敏感隐私。

## 🚀 快速上手与数据迁移

### 1. 新安装配置流程

1. **开启官方会话隔离**：
   在 AstrBot WebUI「平台设置」中，将 **会话隔离（unique_session）** 设为开启（实现按成员独立记忆与存档的关键）。
2. **准备共享知识库**：
   在 AstrBot WebUI「知识库」中新建一个知识库（例如命名为 `shared_memory`），并配置好 **Embedding 模型**。
3. **配置插件**：
   在插件配置中：
   - 在「**⚙️ 基础与生效范围设置**」的 `memory_groups` 中添加需要启用记忆的群号。
   - 在「**🧠 衰减长时记忆：核心引擎**」中开启 `memory_enabled` 并在 `memory_kb_name` 选择刚刚创建的知识库。
4. **即刻使用**：
   直接在群聊中与机器人常态对话，后台将全自动沉淀长时记忆；随时发送 `/好感度` 或 `xxti` 体验互动。

### 2. 存量用户数据平滑迁移

- **旧版好感度（`astrbot_plugin_favorability`）**：
  **全自动零配置迁移！** 插件在初始化时会自动扫描原插件数据目录（包括各人格子目录），自动无损转换并导入所有老用户的好感数值、自由关系与评价。迁移成功后可安全停用或卸载旧好感度插件。
- **旧版记忆会话（`astrbot_plugin_isolated_session`）**：
  若之前使用过旧插件，可在旧插件中使用官方提供的导出工具一键迁移上下文，并在本插件中直接使用原有知识库与 `whitelist_groups` 群聊配置。

## ❓ 常见问题 (FAQ)

<details>
<summary><b>Q1: 为什么提示「全局开关未开启」或「群未在启用列表中」？</b></summary>

- 请检查插件配置面板中的「⚙️ 基础与生效范围设置」，确认 `memory_groups` 列表中已添加当前群号，且群内 `memory_enabled` 为开启状态。
- 确认「🧠 衰减长时记忆：核心引擎」中的 `memory_enabled` 总开关已打开。
</details>

<details>
<summary><b>Q2: 发送 /好感度 或 xxti 时提示图片渲染失败怎么办？</b></summary>

- 本插件采用本地 **Pillow (PIL)** 超采样渲染，不需要安装 Chrome 或 Playwright。
- 请确保当前 Python 环境已安装 Pillow（`pip install pillow`）。若出现环境极端缺失字体等异常，插件将自动无感降级为排版优雅的纯文本消息输出。
</details>

<details>
<summary><b>Q3: 会话重置（/会话重置）会清空我的好感度或存档吗？</b></summary>

- **绝对不会！**
- 好感度数值、自由羁绊关系、即时心境以及历史命名存档均受到独立受保护存储。
- 默认情况下，`/会话重置` 仅会同步清除当前人格对该用户的阶段性“印象评价”（重置为初遇时的初印象），其余所有核心数据均完好保留。
</details>

<details>
<summary><b>Q4: 为什么大模型有时候不主动修改好感度或提议关系？</b></summary>

- 自由式好感系统不强迫大模型每句话都机械输出标签。
- 插件在系统提示词中注入了优雅自然的引导规范，大模型会在话题转折、情感共鸣或关键互动时自发决定是否打标签；当未打标签时，常规互动依然会自动获得基础好感成长与心境自愈。
</details>
