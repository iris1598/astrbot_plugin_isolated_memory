## 一、系统整体架构与发现机制

- **配置文件目录**：`characters/`（支持 `*.json`、`*.yaml`、`*.yml`，自动加载）
- **图片素材目录**：`characters/images/`（推荐命名 `<角色名>_chibi.png` 或 `<角色名>.png`）
- **匹配计算引擎**：用户的日常记忆向量与角色 `anchors` 计算余弦相似度 + 时间衰减权重，**大模型只负责撰写 1~2 句寄语评语，绝不参与打分排序**。
- **海报渲染器**：全域榜单**默认截断展示 Top 5**，防止海报过长；自动按角色名模糊读取图片。

## 二、角色配置文件规范（JSON / YAML）

每个角色对应 `characters/` 下的一个独立文件，文件名推荐命名为 `<角色拼音或代号>.json`（例如 `jiyan.json` 或 `changli.yaml`）。

### 必需与可选字段定义：

| 字段名 | 类型 | 是否必填 | 作用与说明 | 范例 |
| :--- | :--- | :---: | :--- | :--- |
| `id` | `string` | **必填** | 角色唯一英文代号/小写拼音，用于索引与缓存 | `"jiyan"`, `"changli"`, `"aemis"` |
| `name` | `string` | **必填** | 角色中文名，也是素材匹配与海报展示的主要名称 | `"忌炎"`, `"长离"`, `"爱弥斯"` |
| `title` | `string` | 推荐 | 称号或剧情身份定位（**严禁写气动/衍射等属性**） | `"夜归军领军"`, `"远航星"`, `"巡尉"` |
| `tagline` | `string` | 推荐 | 核心座右铭或最经典金句台词，展示于海报核心区 | `"虽千万人，吾往矣。"` |
| `tags` | `list[str]` | **必填** | 4 个心智/性格特质词（每个词建议 4 个汉字） | `["沉稳坚毅", "统帅大局", "心怀苍生", "克制深沉"]` |
| `desc` | `string` | 推荐 | 40~80 字的角色心智内核与性格速描 | 概括处事哲学与精神气质 |
| `quotes` | `list[str]` | 推荐 | 3~5 句经典台词集合，提供给 LLM 评语参考和降级回退 | `["台词1", "台词2"]` |
| `anchors` | `list[str]` | **必填** | **3~5 条用于向量比对的心智语义锚点**（决定匹配精准度） | 见下文核心规范 |

> ⚠️ **重要红线**：
> 1. **切勿添加战斗属性字段（如 `element: 气动/衍射`）**：鸣潮剧情角色/NPC与共鸣者各异，且测试系统只关照“心智人格同频”，严禁标注属性！
> 2. **切勿在角色名中夹杂无关符号**：使用官方规范中文名（如 `爱弥斯`、`西格莉卡`、`陆·赫斯` 或 `陆赫斯`）。

## 三、从官方剧情文档提炼字段的标准方法论（核心重点）

当拿到官方剧情文案（主线/伴星任务剧本、角色好感度语音集、珍藏品记述、人物小传）时，按如下四步提取：

1. **提取 `tagline`（灵魂金句）**：
   - 翻看角色的【信条】、【战斗结算台词】或剧情高光转折点的核心对话；
   - 选取最能体现该角色世界观与执念的一句话（20 字以内为佳）。
2. **提炼 `tags`（4 个特质词）**：
   - 必须反映**心理与为人处世维度**，而非外貌特征；
   - 推荐 4 字成语或偏正短语，例如：
     - 理性学者型：`["理性严谨", "求真求实", "远瞩深空", "不苟言笑"]`
     - 豁达游侠型：`["灵动豁达", "游戏人间", "浪漫执着", "赤子之心"]`
     - 孤勇守护型：`["宿命清醒", "孤光守望", "向死而生", "温良坚韧"]`
3. **精炼 `desc`（性格与心智速描）**：
   - 重点说明该角色如何面对挫折、如何对待同伴、信奉何种处事哲学。
4. **归纳 `anchors`（构建语义向量锚点）**：
   - 这是决定模型能否把用户匹配到该角色的**最核心环节**，必须严格遵循下文规则。

## 四、语义锚点 (anchors) 编写铁律（绝不可犯错）

### 🚨 核心原理
匹配算法执行的是：
$$\text{CosineSimilarity}(\text{Embedding}(\text{用户长期记忆}), \text{Embedding}(\text{角色锚点}))$$

用户在 AstrBot 中保存的记忆绝大多数是**现实日常琐事、心情起伏、对待工作学习生活的态度**（例如：“今天加班到深夜但把项目交付了很有成就感”、“跟朋友约了去海边”、“最近压力大但依然想坚持练琴”）。

### ❌ 致命错误示例（严禁编写）：
- ❌ `"忌炎率领夜归军在北落野抵御鸣潮暴动"`（用户的现实生活不可能去打怪，余弦相似度极低，永远匹配不上！）
- ❌ `"莫宁是黑海岸的研究员，负责观测星空奇迹数据"`（这是第三人称剧情事实，不是心智特征）
- ❌ `"手持青龙长枪，拥有风属性共鸣能力的将军"`（纯战斗外貌设定，无任何心理学共鸣价值）

### ✅ 黄金标准示例（必须遵循）：
**每条锚点必须以「用户」为主语，描述一种鲜明的思维模式、性格特质、处事态度或生活价值取向：**

#### 案例 1：忌炎（沉稳领袖、孤勇担当、顾全大局）
```json
"anchors": [
  "用户性格沉稳刚毅，在复杂或高压局面下能够保持清醒理性，展现出统御全局与身先士卒的担当意识",
  "用户在面对困难与危机时从不推卸责任，行胜于言，习惯默默承担压力以守护身边的同伴",
  "用户极度重视承诺与原则，具有坚忍不拔的执行力，宁愿自己负重前行也要坚守内心的道义与责任"
]
```

#### 案例 2：爱弥斯（灵动豁达、浪漫赤诚、童心未泯、乐观游戏）
```json
"anchors": [
  "用户性格乐观豁达，面对生活的琐碎与挫折时善于用幽默感和达观心态化解压力",
  "用户富有浪漫主义情怀与未泯的童心，对未竟的梦想与纯粹的热爱保持着执着探索的少年心气",
  "用户重视真挚的同伴羁绊，为人随和坦荡，享受在不设限的世界中发现新奇与美好"
]
```

#### 案例 3：折枝（内敛专注、细腻自省、执着于热爱）
```json
"anchors": [
  "用户性格文静内敛，不喜喧嚣浮躁的社交，习惯沉浸在自己热爱的专业或创作领域中精益求精",
  "用户心思极其细腻敏锐，情绪真挚而丰富，善于观察生活微小的美好与人情冷暖",
  "用户虽然表面谦逊温和甚至偶有犹豫，但内心对自身认同的原则与热爱有着不可动摇的坚守"
]
```

## 五、Q 版人物素材截图与裁切流程

系统已内置固定坐标裁切工具：[`crop_characters.py`](file:///C:/Users/84637/Desktop/code/astrbot_plugin_isolated_session/crop_characters.py)。

### 1. 截图获取标准
- **分辨率**：必须为 **1920×1080** 游戏原生截图；
- **场景**：游戏内「人格弹珠」活动角色选择界面（中央展示角色完整 Q 版立绘）。

### 2. 裁切坐标规范
- 裁切框坐标：`left=569, top=296, right=1118, bottom=845`
- 裁切后输出分辨率：**549×549** 纯正方形 PNG。

### 3. 一键裁切命令（推荐）
在终端中执行下列命令即可自动将角色裁剪并存入插件素材库：

```bash
# 语法: python crop_characters.py <截图路径> -n <角色名>
python crop_characters.py "C:/Users/84637/Desktop/jiyan_raw.png" -n 忌炎
```
> 输出结果将直接保存为：`characters/images/忌炎_chibi.png`。

### 4. 自动匹配命名规则
海报渲染器支持自动寻找，保存为以下任意一种均可被系统识别：
- `characters/images/<角色名>_chibi.png`（最推荐，如 `忌炎_chibi.png`）
- `characters/images/<角色名>.png`（如 `忌炎.png`）
- `characters/images/<id>_chibi.png`（如 `jiyan_chibi.png`）

## 八、自检与测试验证清单

新角色添加完毕后，请按以下 4 点进行自查：

1. **[ ] 格式校验**：JSON 逗号与引号正确无误，或者 YAML 缩进无 Tab。
2. **[ ] 属性剔除**：确认**没有**编写 `element` 字段。
3. **[ ] 锚点人称**：确认全部 `anchors` 均以 **“用户...”** 开头，描述性格与思维模式。
4. **[ ] 素材检验**：确认 `characters/images/<角色名>_chibi.png` 文件已存在，尺寸为 549×549。
5. **[ ] 运行测试**：在仓库根目录执行以下命令，确保所有单元测试全部通过：
   ```bash
   python -m unittest discover -s astrbot_plugin_isolated_session/tests -p "test_*.py"
   ```
